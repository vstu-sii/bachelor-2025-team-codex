# MVP Scope — Sprint 4/5 (SA/PO)

## Цель MVP
Доставить минимально-ценную версию Auto-Flashcards для Demo Day: пользователь может создать набор карточек из материала, отредактировать набор, пройти SRS-сессию, посмотреть базовую статистику и управлять профилем.

Источник требований: Use Cases UC-1..UC-5 (Lab 5).  

## In Scope (Must-have)
### UC-1 — Создание набора карточек из учебного материала
- Импорт учебного материала (PDF/DOCX/TXT) и генерация карточек
- Preview + сохранение набора

### UC-2 — Редактирование и улучшение набора карточек
- Редактирование Q/A + удаление карточек
- Объединение дублей (минимально)

### UC-3 — Ежедневное повторение (SRS-сессия)
- Выбор карточек "на сегодня"
- Оценка запоминания и пересчет интервалов
- Сохранение прогресса при выходе из сессии

### UC-5 — Управление профилем
- Просмотр/изменение базовых настроек (язык/тема/сложность)
- Валидация ввода

## Should-have
### UC-4 — Просмотр статистики и прогресса (базовый уровень)
- Количество карточек, процент правильных ответов, период (день/неделя/месяц)
- Сообщение "нет данных" при первом запуске

## Out of Scope (для Demo Day)
- Экспорт PDF отчетов
- Расширенные рекомендации/персонализация
- Продвинутые роли (преподаватель) — оставляем как будущую итерацию

## Definition of Done (DoD) / Acceptance для MVP
- UC-1: обработка файла < 60 сек, >= 30 карточек для лекции ~20 страниц, понятные ошибки пользователю
- UC-3: прогресс не теряется, интервалы повторений обновляются корректно
- UC-4: корректное отображение данных, фильтрация/период без заметных задержек
- UC-5: корректная валидация, подтверждение критичных действий (сброс прогресса)
